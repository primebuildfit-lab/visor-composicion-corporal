# Visor de composición corporal (beta)

Versión compilada de la beta del visor 3D educativo de composición corporal. Este repositorio solo contiene los
archivos publicados: el código fuente no está aquí.

- Software y datos de terceros, con sus licencias y atribuciones: `legal/avisos-terceros.txt`.
- Modelo humano base: MakeHuman / MPFB (CC0). Entornos: panoramas HDRI de Poly Haven (CC0).
